# FOSS Atlas v0.2

GitHub-ready static prototype.

## Structure
- index.html — application shell
- styles.css — design
- app.js — functionality
- data/ — external master database files
- README.md — documentation only

## Important
The website loads JSON from `data/`, so all files must be published together. This separates the UI from the master data and prepares the project for automated update workflows.

## GitHub Pages
Publish the `main` branch root. Then embed the resulting Pages URL in Google Sites or Zoho Sites.

The included records are starter metadata, not the final verified master database.
